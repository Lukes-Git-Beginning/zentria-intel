- [cybersecuritynews.com](https://cybersecuritynews.com/anthropic-claude-hidden-code/) (Community-Kontext)

**Was passiert:**
Ein Entwickler hat am 30.06. entdeckt, dass Claude Code seit mindestens 3 Monaten unsichtbare Unicode-Steganographie-Marker in System-Prompts einbettet — ohne Dokumentation, ohne Nutzer-Disclosure. Die Mechanik ist präzise:

- **Date-Separator-Flip:** Das Datum "2026-06-30" wird mit einem Standard-Bindestrich oder einem Unicode-Slash kodiert, je nachdem ob die System-Timezone auf `Asia/Shanghai` oder `Asia/Urumqi` gesetzt ist.
- **Apostroph-Substitution:** Das Apostroph in "Today's" wechselt zwischen vier visuell identischen Unicode-Zeichen, abhängig davon ob der Proxy-Hostname auf bekannte chinesische KI-Labor-Domain-Listen matched.

**Hintergrund:** Im Februar 2026 hatten Anthropic, OpenAI und Google koordinierte industrielle Model-Distillation-Angriffe publiziert. Anthropic beschuldigte DeepSeek, Moonshot AI und MiniMax, über 24.000 fraudulöse Accounts mit 16+ Millionen Exchanges für Model Distillation genutzt zu haben. Die Steganographie war Anthropics technische Gegenwehr — Fingerprinting zur Identifikation dieser Proxies, offensichtlich ohne Legal- oder PR-Review implementiert.

Anthropic hat die Existenz bestätigt. Version 2.1.197 von Claude Code entfernt den Code — aber das offizielle Changelog erwähnt die Steganographie mit keinem Wort. HN #1, Score 1528, 439 Kommentare in 24h.

**Was bedeutet das für Cosmi?**
Zwei getrennte Implikationen:

1. **Tooling (sofort):** Claude Code auf ≥ 2.1.197 updaten. Das Datenschutz-Risiko war auf Anthropic-interne Proxy-Detektion beschränkt — keine Kunden-Daten wurden extrahiert. Aber Entwickler-Vertrauen ist beschädigt.

2. **Positioning (mittel- bis langfristig):** HN-Score 1528 zeigt die Geschwindigkeit, mit der Entwickler-Vertrauen in Black-Box-AI-Tools erodiert. "Anthropic hat unangekündigt Tracking-Code eingebettet" wird in Kundengesprächen auftauchen. Cosmi-Antwort muss stehen: "Cosmi-AI läuft auf Ihrem Server. Wir haben keinen Zugriff auf Ihre Prompts, keine unsichtbaren Marker, kein Cloud-Routing ohne Ihre Kontrolle." #### BSI-Cluster KW27: Ruby ERB RCE + NGINX Heap-Overflow + OpenSSL (n_sources:3, score:0.83/0.82/0.69)

**Quellen:**
- BSI [WID-SEC-2026-1187](https://wid.cert-bund.de/portal/wid/securityadvisory?name=WID-SEC-2026-1187) — Ruby ERB
- BSI [WID-SEC-2026-1527](https://wid.cert-bund.de/portal/wid/securityadvisory?name=WID-SEC-2026-1527) — NGINX
- BSI [WID-SEC-2026-0995](https://wid.cert-bund.de/portal/wid/securityadvisory?name=WID-SEC-2026-0995) — OpenSSL

**Was passiert:**

**Ruby ERB — CVE-2026-41316 (CVSS 8.1, BSI: kritisch):**
Bypass des `@_init`-Deserialization-Guards via drei ungeschützte `eval()`-Methoden: `ERB#def_method`, `ERB#def_module`, `ERB#def_class`. Jede Rails-App die `Marshal.load` auf untrusted Data aufruft und sowohl `erb` als auch `activesupport` geladen hat, ist für RCE durch unauthentifizierten Remote-Angreifer anfällig. Legacy-Rails-Apps (pre-7.0) mit Marshal-Cookie-Session-Serialisierung besonders gefährdet. **Fix:** Ruby 4.0.3. Sichere Rails-Versionen: 7.2.3.1, 8.0.4.1, 8.1.2.1.

**NGINX — CVE-2026-42945 + weitere (BSI: kritisch):**
Heap Buffer Overflow in `ngx_http_rewrite_module` (CVE-2026-42945) — 18 Jahre im Code, betrifft NGINX 0.6.27 bis 1.30.0. Zusätzlich: HTTP/3/QUIC-Modul RCE-Potenzial in 1.31.0-1.31.1. F5 hat außerplanmäßige Updates veröffentlicht. **Fix:** NGINX 1.30.3 (Stable-Branch), 1.31.2 (Mainline-Branch).

**OpenSSL — Multiple (BSI: hoch):**
DoS, Daten-Offenlegung, unspezifiziert. Betrifft praktisch jeden TLS-Stack (Go, Python, Ruby, Node.js mit nativen Bindings). Patches verfügbar.

**Was bedeutet das für Cosmi?**
Drei gestaffelte Sofortmaßnahmen:
1. **Sofort (heute/morgen):** NGINX-Version prüfen und auf 1.30.3 oder 1.31.2 updaten. NGINX ist Standard-Reverse-Proxy in Self-Hosted-Stacks — dieser CVE ist breiter als jeder andere KW27-Advisory.
2. **Diese Woche:** OpenSSL-Patches anwenden. Alle Go/Python/Ruby-Services mit TLS betroffen.
3. **Ruby/Rails-Prüfung:** Falls Cosmi Ruby-basierte Services oder Gems nutzt (oder Kunden-Deployments): CVE-2026-41316 abklären. Marshal-Cookie-Sessions eliminieren falls vorhanden.

KW27 hat damit fünf kritische/hohe Security-Advisories in zwei Tagen produziert (Node.js, Budibase, Coolify, Gitea aus Mo + Ruby/NGINX/OpenSSL heute). Cosmi-Security-Patch-Zyklus prüfen — ist KW27-Response-Prozess definiert?
