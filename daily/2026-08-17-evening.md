#### Cloudflare Wallets + x402: AI-Agenten zahlen autonom für APIs (n_sources:4, score:8.6)

**Quelle:**
- [Heise.de](https://www.heise.de/news/Cloudflare-Wallets-Automatisierte-API-Zahlungen-fuer-KI-Agenten-11400345.html)

**Was passiert:**
Cloudflare baut eine Wallet-Infrastruktur für autonome AI-Agenten-Zahlungen auf Basis des **x402-Protokolls** (HTTP 402 "Payment Required" als Protokoll-Extension):

1. Server antwortet mit HTTP 402 + Base64-JSON mit Zahlungsanweisungen
2. Client (AI-Agent) sendet `PAYMENT-SIGNATURE`-Header mit kryptographisch signierter Autorisierung
3. Server bestätigt mit `PAYMENT-RESPONSE`-Header

Technische Basis: EIP-712-Signaturen auf EVM-Netzwerken, derzeit Stablecoins. Visa/Mastercard/Stripe-Support geplant. Aktuell: `cloudflare.pay` — nur Username-Reservierung, keine Live-Funktion. Wallets sind per Agent isoliert mit separaten Budgets und Spending-Limits.

**Cross-References:**
- Stripe/OpenRouter (i01 desselben Tages) — selbe Infrastruktur-Schicht, verschiedene Anbieter.
- → **Trend-Alert: Agentic-Payment-Infrastructure** konvergiert heute aus zwei unabhängigen Quellen.

**Was bedeutet das für Cosmi?**
