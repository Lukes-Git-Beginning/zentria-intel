**Was passiert:**
BSI hat das Security Advisory WID-SEC-2026-1544 für PostgreSQL mit Einstufung **hoch** aktualisiert. Laut Morning-Report-Kontext adressiert der Advisory mehrere Schwachstellen, die RCE, DoS, Information Disclosure und Authentication Bypass ermöglichen. Das Advisory wurde am 2026-07-06 10:31 Uhr aktualisiert — zeitgleich mit WID-SEC-2026-2166 (Red Hat Satellite), was auf ein koordiniertes BSI-Patch-Release-Fenster hinweist. Die BS-Portal-Seiten sind JavaScript-rendered und nicht direkt scrapbar; für Volldetails muss das Portal direkt oder via CVE-Datenbank-Lookup konsultiert werden.

**Cosmi-Stack-Relevanz:**
Cosmi nutzt PostgreSQL als primäre Datenbank (`backend/internal/core/db/`). Eine hoch-eingestufte BSI-Warnung mit RCE-/Auth-Bypass-Potenzial ist **P0-Pflicht-Check**. Action Required:
1. PostgreSQL-Version im Produktions- und Staging-Stack identifizieren
2. Aktuelle Patchversion aus `postgresql.org/support/versioning/` vergleichen
3. Patch-Zeitfenster planen — keine offene RCE in der DB-Schicht vor nächstem Sprint-Start akzeptabel

**Was bedeutet das für Cosmi?**
PostgreSQL-Schwachstellen sind die gefährlichste Kategorie für ein Multi-Tenant-SaaS mit Kundendaten. Auth-Bypass in Kombination mit RCE würde bedeuten, dass ein Angreifer Mandantendaten aus anderen Tenants lesen kann — ein GAU unter DSGVO. `backend/internal/core/db/migrations/` und `infrastructure/postgres/` müssen Patch-Status-Verifikation als CI-Check erhalten, bevor das Advisory geschlossen wird. Empfehlung: Patch heute Abend oder spätestens im ersten Sprint-Slot morgen früh.

1. **Input Constraints** — Kann User physisch interagieren? (Hände frei?)
2. **Output Constraints** — Kann User Bildschirm lesen?

4. **Cognitive Load** — Wie viel mentale Kapazität ist bereits gebunden?

**Modalitäten-Matrix (Auswahl):**

| User-Intent | Empfohlener Input | Empfohlener Output | Kontext-Beispiel |
|---|---|---|---|
| Schnellstatus (Hände besetzt) | Voice/Button | Audio/Alert | Techniker im Außendienst |
| Detailanfrage (fokussiert) | Chat | Kurzer Text | Büro-Arbeit |
| Komplexe Analyse (Schreibtisch) | GUI/Filter | Visual Dashboard | Manager-Reporting |
| Creative (Design) | Multi-modal | Interactive Canvas | Designer-Workflow |

Schlüsselaussage: *"Modality choices should multiply pathways to information"* — nicht eine Modalität für alle, sondern Cross-Modality Handoffs innerhalb von Workflows.

**Was bedeutet das für Cosmi?**
Cosmi adressiert branchengemischte KMU-Teams: Büroangestellte, Techniker, Außendienst, Management. Das Framework gibt direkten Guidance für Modul-spezifische AI-UX:

- **Cosmi-Dialer (Außendienst):** Voice als primäre Modalität für AI-Interaktion während Calls
- **Cosmi-Schichten (Feldmitarbeiter):** Button-basierte Bestätigungen, Audio-Feedback — kein Chat
- **Cosmi-Rapporte (Management):** Visual Dashboard-Outputs, nicht Text-Dumps
- **Cosmi-CRM (Büro):** Chat + Inline-Suggestions als primäre AI-Modalität
